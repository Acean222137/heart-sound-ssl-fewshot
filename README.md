# 基于自监督少样本学习的心音信号表征学习与心脏异常分类

SRTP 项目仓库：面向心音信号（PCG）的自监督表征学习与心脏异常分类研究。

## 项目简介

本项目针对心音信号标注样本稀缺的问题，研究自监督少样本学习方法：

1. **信号预处理**：采用 Springer HMM 方案进行心音分段，每条记录提取 3 个心动周期，并通过数据增强生成约 30% 虚拟样本；
2. **表征学习**：在自建与公开心音数据集上进行自监督预训练，学习可迁移的心音表征；
3. **异常分类**：在少样本条件下进行心脏异常分类，并开展跨数据集迁移微调与测试。

训练协议：每个数据集 50% 用于训练，目标数据集 10% 用于迁移微调，剩余 40% 用于测试。

## 数据集

| 数据集 | 说明 | 获取方式 |
| --- | --- | --- |
| PhysioNet/CinC 2016 | 心音分类挑战赛公开数据 | [challenge-2016/1.0.0](https://physionet.org/content/challenge-2016/1.0.0/) |
| CirCor DigiScope 2022 | 目前最大规模的公开儿科心音数据集 | [circor-heart-sound/1.0.3](https://physionet.org/content/circor-heart-sound/1.0.3/)（需注册并签署使用协议） |
| NHS 临床试验数据 | 导师提供的自测临床数据（光学听诊器） | 课题组内部使用 |

> **重要声明**：所有心音数据（尤其是 NHS 临床试验数据）均不包含在本仓库中，也不会上传。数据仅在本地使用，获取方式见 `data/README.md`。
